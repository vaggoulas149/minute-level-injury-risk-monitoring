# Beyond Session-Level Injury Prediction

This repository contains the anonymous implementation accompanying the paper:

**"Beyond Session-Level Injury Prediction: A Multimodal Framework for Continuous Minute-Level Injury-Associated Risk Monitoring in Football"**

## Overview

This work proposes a multimodal machine learning framework for continuous minute-level injury-associated risk estimation using wearable monitoring data collected during football training.

The framework integrates:

- minute-level physiological and biomechanical wearable measurements
- workload and wellness information
- temporal feature engineering
- athlete-specific personalization
- XGBoost-based injury-associated risk estimation
