# Reproducibility and Provenance Notes

## Canonical analysis lineage

Notebook 01 reconstructs the processed 2020 SoccerMon resource.

Notebook 03 creates the canonical modelling table and freezes the ordered 63-feature CUM+DYN representation.

Notebook 04 freezes the deterministic outer-fold athlete assignments and generates the current-environment baseline OOF predictions.

Notebook 05 reuses Notebook 04 folds and baseline OOF predictions for the TabPFN benchmark.

Notebook 06 reuses Notebook 03 features and Notebook 04 folds for the augmentation benchmark.

## Historical RF/XGBoost provenance issue

An earlier archived execution produced Random Forest and XGBoost point estimates that do not exactly reproduce under the current software environment. Logistic Regression reproduces exactly.

Historical tree-model values must therefore be treated as provenance-only outputs and must not be mixed with the current unified-environment benchmark.

The current-environment baseline values are the canonical values for all new comparisons.

Two analyses described in an earlier manuscript were missing as executable cells from the archived modelling notebook:

Both are now reconstructed explicitly in Notebook 04.

## TabPFN reproducibility

The completed TabPFN rerun reproduced the frozen benchmark to numerical precision:

- maximum absolute ROC-AUC difference: approximately 3.9e-7;
- maximum absolute PR-AUC difference: approximately 5.0e-7.

The canonical interpretation is that TabPFN improves later-landmark discrimination relative to Logistic Regression, but does not consistently dominate tree-based baselines.

## Augmentation checkpoint provenance

The augmentation OOF checkpoint contains 827,390 rows and 930 normalized experiment units.

The checkpoint is protected by a row-level experiment fingerprint and a metadata sidecar. A prior one-time migration added the fingerprint to a legacy checkpoint after structural validation. That migration is a provenance caveat: it does not cryptographically prove that every historical row was generated under the exact current configuration.

The publication notebook therefore:

- refuses unfingerprinted legacy checkpoints;
- validates the current experiment fingerprint;
- validates feature and fold fingerprints;
- can regenerate the full grid if the checkpoint is absent.

If computationally feasible before archival publication, a completely fresh full-grid regeneration under a pinned environment would be the strongest final provenance check.

## Bootstrap implementation

The fast weighted bootstrap implementation was validated against scikit-learn weighted ROC-AUC and average precision on 50 athlete-bootstrap replicates to tolerance 1e-12.

## Data limitation

The dominant inferential ceiling is the effective number of positive clusters:

- 22 injury-associated athlete-sessions;
- only 5 athletes contributing all positive sessions.

No resampling, synthetic augmentation, or bootstrap procedure changes that fact.

## Public-release checklist

Before tagging a public release:

- verify all six notebooks with `Restart Kernel -> Run All`;
- confirm no access tokens or account identifiers appear in saved outputs;
- inspect committed notebook outputs for accidental raw-data leakage;
- confirm the raw SoccerMon dataset is not committed;
- decide the repository code license after verifying data/code redistribution rights;
- replace or isolate any author-local raw-data path in Notebook 01 if full portability is required;
- archive exact runtime version files generated by Notebooks 04–06;
- ensure manuscript tables and figures use only canonical current-environment outputs.
